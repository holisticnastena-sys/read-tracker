# Reading Tracker v2

Готовый статический книжный трекер для GitHub Pages. Данные берутся из `books.xlsx` прямо в браузере.

## Структура

- `index.html` — сайт
- `css/styles.css` — дизайн
- `js/app.js` — логика
- SheetJS подключается через CDN для чтения Excel
- `books.xlsx` — данные

## Ожидаемые столбцы Excel

`Название | Автор | Серия | Книга в серии | Статус | Формат | Страницы | Часы | Прочитано страниц | Прослушано часов | Начало | Конец | Длительность чтения, дней | Оценка | Обложка`

### Статусы

- `К прочтению`
- `Читаю`
- `На паузе`
- `Прочитано`
- `Брошено`

### Форматы

- `Книга`
- `Аудиокнига`
- `Комикс`

## Как разместить на GitHub Pages

1. Замени содержимое своего репозитория файлами из этой папки.
2. Убедись, что `books.xlsx` лежит в корне рядом с `index.html`.
3. Commit + Push.
4. В GitHub: **Settings → Pages → Deploy from a branch → main / root**.
5. После публикации открой страницу и сделай жёсткое обновление (`Ctrl+F5`).

## Как обновлять книги

Меняй только `books.xlsx`, затем загружай новую версию в репозиторий. Код сайта менять не нужно.

## Важно

Если открыть `index.html` двойным кликом (`file://`), браузер обычно блокирует загрузку Excel. Проверяй сайт через GitHub Pages или локальный сервер, например:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`.
